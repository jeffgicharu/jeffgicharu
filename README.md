# Jeff Gicharu

I'm a software engineer, and I build software that holds up in any domain. I have built for a telecom, for merchants taking payments and for the recycling industry, including ERP and CRM systems. I design the system, build it end to end, and run the server it ships to.

My portfolio, with the story behind each project, is at **[jeffgicharu.com](https://jeffgicharu.com)**.

## Recent work

Each of these is a live site with every journey working end to end. The businesses are invented, but each site is built, deployed and run like a real one, through its own release pipeline on a server I manage.

| Project | What it is | Built with |
| --- | --- | --- |
| **[Ukingo](https://ukingo.jeffgicharu.com)** · [code](https://github.com/jeffgicharu/ukingo) | A booking site for a lodge near Mount Kenya. Guests see the price of every night and pay a deposit, and staff run the front desk and the room calendar. | Next.js, React, TypeScript, PostgreSQL |
| **[Roomwave](https://roomwave.jeffgicharu.com)** · [code](https://github.com/jeffgicharu/roomwave) | Live polls, quizzes and questions that a whole room answers on their phones, with the results moving on the big screen as answers arrive. | Node, Fastify, Socket.IO, Svelte, PostgreSQL, Redis |
| **[Sebule](https://sebule.jeffgicharu.com)** · [code](https://github.com/jeffgicharu/sebule) | An online furniture store with M-Pesa checkout, and a back office for orders, stock and the catalogue. | Laravel, PHP, PostgreSQL, Redis |

## Earlier projects

- **[rustlb](https://github.com/jeffgicharu/load-balancer)** is a Layer 4 and 7 load balancer in Rust, with health checks and hot config reload.
- **[rustdb](https://github.com/jeffgicharu/kv-database)** is an embedded LSM-tree key-value database in Rust, with MVCC transactions and a write-ahead log.
- **[ContractorOS](https://github.com/jeffgicharu/ContractorOS)** is a contractor management platform built with Next.js, NestJS and PostgreSQL.
- **[wallet-api](https://github.com/jeffgicharu/wallet-api)** and **[wallet-app](https://github.com/jeffgicharu/wallet-app)** make up a mobile money wallet, with a Spring Boot API and a React app.
- **[ussd-simulator](https://github.com/jeffgicharu/ussd-simulator)** is a USSD menu service in Spring Boot, with a browser phone for trying it.

## What I work with

I write TypeScript, JavaScript, Java, Python, PHP, Go, Rust and SQL. I build with React, Next.js, Svelte, Node, Spring Boot, Laravel and NestJS, and with React Native and Salesforce for mobile and business systems. My data lives in PostgreSQL, Redis and SQLite, and I ship through GitHub Actions to Linux servers running nginx and systemd behind Cloudflare.
